# 天空裂洞物語（雛形）

中世紀村莊的天空破了一個大洞，村民搭熱氣球飛上去，一層一層往上探險的掛機遊戲。
手機直式設計，電腦瀏覽器打開會顯示成置中的手機寬度。

**線上試玩：** https://sky-rift-idle.vercel.app

## 需求起因

看到朋友用「純網頁 + GitHub Pages」做的遊戲，手機和電腦開瀏覽器就能玩、免費上線，很方便，
於是想用同樣的方式做一款自己的掛機遊戲。美術之後自己產出，先把玩法雛形做出來：
中世紀世界觀、往天空裂洞一層層爬、裝備紙娃娃、飛空艇改裝、家園布置、職業轉職、夥伴、技能 Build。

## 怎麼玩

直接雙擊 `index.html` 就能玩（不需要伺服器、不需要安裝任何東西）。
進度自動存在瀏覽器裡，關掉再開會結算離線收益（最多 8 小時）。

## 多語系

支援 **繁體中文、English、简体中文**，右上角 ⚙️ 設定可以切換。第一次開啟會依瀏覽器語言自動選。

- 所有顯示文字都在 `lang/<語言>.js`，程式裡用 `G.t('key')` 取字
- **改文案**：直接改 `lang/` 裡的檔案
- **加新語言**：複製 `lang/en.js` 改名翻譯 → 在 `js/i18n.js` 的 `G.LANGS` 加一行 → `index.html` 加一個 `<script>`
- 缺字的 key 會退回繁體中文

## 檔案結構

```
index.html          頁面骨架
style.css           介面樣式
js/data.js          ★ 所有數值與內容（職業、技能、怪物、夥伴、家具……）調平衡改這裡
js/i18n.js          多語系核心（G.t、語言設定、裝備/技能名稱組合）
lang/*.js           ★ 各語言的文字（繁中 zh-TW 為主，en、zh-CN）
js/state.js         存檔、屬性計算、玩家操作
js/art.js           暫代美術（程式畫的）
js/battle.js        戰鬥場景（Phaser）
js/ui.js            六個分頁的介面
js/main.js          啟動、離線收益、自動存檔
assets/manifest.js  自製美術登記表
vendor/phaser.min.js 遊戲引擎 Phaser 3.80.1
```

## 換成自己畫的圖

目前所有圖都是程式畫的暫代圖。怪物圖已經可以直接替換：

1. 圖片放到 `assets/monsters/`，建議 128×128、透明背景、**面向左**、腳踩在圖片底部
2. 在 `assets/manifest.js` 登記，例如：
   ```js
   'mon_slime#7ec8e3': 'assets/monsters/cloud_slime.png',
   ```
   key = `mon_` + 造型 + 顏色（對照 `js/data.js` 的 `MONSTER_TIERS`）

主角、夥伴的紙娃娃、背景、飛空艇之後再接上替換機制。紙娃娃的圖要分層畫：
身體、頭髮、頭盔、鎧甲、靴子、武器各一張，同樣大小疊在一起。
